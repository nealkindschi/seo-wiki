# Broken Link Building: The Complete Guide

Source: https://ahrefs.com/blog/broken-link-building/
Author: Joshua Hardwick (former Head of Content, Ahrefs)
Published: 2022-05-23

## Core Premise
Broken link building is the 5th most popular link-building tactic (Aira survey, 250+ professionals) — legitimate but nuanced; success depends on execution and value proposition, not the tactic itself.

## Definition
Find defunct pages that still have backlinks, then persuade site owners to replace those broken links with links to your relevant replacement content.

## 4-Step process
1. **Find broken pages with backlinks** — four tactics: (a) competitor analysis via Site Explorer "Best by links" filtered to 404s, sorted by referring domains; (b) topic-wide search via Content Explorer for broken pages on a subject with 20+ referring domains; (c) outbound-link analysis — check competitors' own broken outgoing links via Broken Links report, batch-analyze link volume; (d) resource-page mining — Google search for resource pages, then SEO Toolbar to spot dead links.
2. **Vet the link prospects** — filter dofollow only, exclude subdomains, DR 5+, domain traffic 20+ minimum; distinguish "deep links" (specific recommendation reason) from "general links" (vague endorsement); note *why* sites linked originally.
3. **Create replacement content** — study the original via Wayback Machine to match structure; incorporate points deep-linkers specifically referenced; add improvements (templates, clearer explanations, updated stats).
4. **Execute outreach** — segmented, personalized templates per deep-link reason rather than one generic mass email; generic templates for general-link segment; hybrid personalization-at-scale approach.

## Key data
- Example: Content Marketing Institute had 134 dead pages, some with 50+ referring domains — illustrates opportunity scale.
- Core insight: "Link building tactics are just streamlined ways of finding link prospects with a reason for contact."
