# How to Optimise PDF Files for SEO

Source: https://digitalchakra.co.uk/blog/how-to-optimise-pdf-files-for-seo/

## 11 Core Optimization Tips
1. Create Unique Content — original, rich material distinct from web pages. "Google loves good content even if it is not your web pages."
2. Title & Description Metadata — SEO titles (50-60 chars, keyword at start), descriptions (<160 chars); keywords in filename, subject, URL
3. Optimize File Name — keyword-rich, concise, hyphen-separated (e.g. "seo-detailed-guide.pdf"); avoid punctuation/stop words/excess length
4. Anchor Text Strategy — "Links from the pages of your website to the PDFs are crucial SEO signals"; use descriptive anchor text; write-protect PDFs
5. Internal Linking — link from PDFs to website pages to pass authority signals and guide readers
6. Header Tags & Structure — use real header tags (h1/h2/h3), not just bold text; incorporate target keywords naturally
7. URL Optimization — keywords in PDF URLs separated by dashes (WordPress-friendly; limited on Wix/Shopify)
8. Alt Text for Images — descriptive alt text (≤100 chars) for accessibility and searchability
9. File Size Compression — keep file size small for faster loading (Adobe Acrobat "Reduce File Size", or ilovepdf.com)
10. Font Selection — stick to standard fonts (Times, Helvetica, Courier, Symbol, Zapf Dingbats) to avoid embedded-font bloat
11. Mobile Optimization — left-align text, bullet points, heading hierarchies, short paragraphs

## Key Technical Insights
- Indexability: Google indexes searchable PDFs like HTML pages but refreshes them less frequently
- Ranking likelihood: "A Web document is more likely to rank higher than a PDF in 9 out of 10 cases"
- Non-indexable PDFs: password-protected, encrypted, or non-static-HTML PDFs won't be indexed
- Images within PDFs currently aren't indexed by Google
- Nofollow links cannot be used within PDF documents
- Duplicate content: same content in both PDF and HTML flagged as duplication; HTML typically ranks higher
- SERP display: PDFs show with a distinctive PDF icon in search results

## Tracking & Prevention
- Download tracking: Google Tag Manager, site header code modifications, or third-party plugins (standard GA doesn't track PDF downloads)
- Preventing indexing: X-Robots-Tag: noindex HTTP header, or Google Search Console URL removal tool

## Tools Referenced
Adobe Acrobat Reader, ilovepdf.com (compression), Google Tag Manager, Google Search Console
