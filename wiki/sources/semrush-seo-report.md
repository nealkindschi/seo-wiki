Carlos Silva, "How to Create an Effective SEO Report in 2026" (Semrush
Blog, published 2026-04-10).

## Key takeaways

- Defines an **SEO report** for the current era as covering both
  regular search *and* AI search performance in one document — AI
  Visibility (a 1-100 score, brand mentions, citation counts) is
  presented as a now-standard reporting section alongside organic
  clicks, CTR, rankings, and backlinks, not an optional add-on.
- Recommended report structure (executive summary → traffic → AI
  Visibility → keyword performance → conversions/ROI → backlinks →
  content performance → technical health → recommended actions) is a
  reusable template for standing client/stakeholder reporting.
- Practical presentation guidance: explain *why* a metric changed, not
  just that it changed; end reports on actionable positives rather than
  a bare list of problems; keep cadence consistent (weekly/monthly/
  quarterly).
- Tool-specific data-gathering map: GSC for clicks/CTR, AI Visibility
  Toolkit for AI metrics, GA4 for conversions, Position Tracking for
  rankings, Backlinks tool + Site Audit for authority/technical health.
