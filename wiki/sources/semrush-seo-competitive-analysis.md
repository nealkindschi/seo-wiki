Carlos Silva, "SEO Competitor Analysis" (Semrush Blog, published
2026-05-29).

## Key takeaways

- Defines **direct vs. organic competitors**: direct = same industry;
  organic = ranks for the same keywords despite operating in a
  different industry (worked example: Men's Health magazine treats
  Gymshark, an apparel brand, as an organic competitor because they
  compete for the same fitness-content search terms). Useful
  disambiguation missing from this wiki's other competitive-analysis-
  adjacent pages.
- 8-step process extends classic keyword/backlink gap analysis
  ([[keyword-mapping-and-cannibalization]]) with an explicit **AI
  visibility** step: use the AI Visibility Toolkit to find prompts
  where competitors appear but you don't, filtered to business-relevant
  prompts — the AI-search equivalent of a traditional keyword gap
  analysis.
- "Reverse-engineer winning pages" step gives a concrete audit
  checklist for competitor content: angle, audience targeting, H2
  structure, format, title tags, and authority signals (original
  research, named frameworks, credibility markers) — a reusable
  competitor-teardown template.
- Off-site presence step (social posting cadence/engagement, Reddit/
  community `site:` searches for sentiment) extends competitive
  analysis beyond owned-site SEO metrics into brand-perception
  territory, overlapping with [[brand-entity-seo-strategy]]'s branded-
  query analysis.
