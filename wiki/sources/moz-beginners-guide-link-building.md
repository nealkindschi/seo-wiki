# Moz — Beginner's Guide to Link Building

URL: https://moz.com/beginners-guide-to-link-building

Moz's foundational explainer on link building: definition (acquiring
external hyperlinks as both a discovery mechanism and a PageRank-style
ranking signal), the Penguin-era shift toward "quality, relevance, and
authenticity," the non-ranking benefits (relationship building, referral
traffic, brand authority), and the core requirement that every campaign
needs "something of value to build links to."
