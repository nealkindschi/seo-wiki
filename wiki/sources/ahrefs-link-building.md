# Ahrefs — Link Building for SEO

URL: https://ahrefs.com/seo/link-building

Ahrefs' comprehensive link-building guide: the four ways links get built
(adding, asking, buying, earning), five link quality metrics (authority,
relevance, anchor text, placement, destination), high-impact strategies
(competitor backlink analysis, targeted outreach, linkable assets, content
promotion, guest posting), and benchmark statistics (~5% cold-outreach
success rate, "a few dozen foundational links" for new sites).
